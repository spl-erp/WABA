# Waba documentation

Waba connects the ERP directly to Meta's WhatsApp Cloud API: a shared inbox for the sales and accounts teams, templates, notifications, reports and health alerts, with every conversation saved on the customer's record.

**Status: documentation for confirmation. Nothing is built or deployed.**

| File | What it is |
|---|---|
| [00_DECISIONS.md](00_DECISIONS.md) | What the owner decided, and what is still open |
| [01_FEATURES.md](01_FEATURES.md) | What the system does, role by role, in plain language |
| [02_DATA_FLOW.md](02_DATA_FLOW.md) | How information moves, with diagrams |
| [03_USER_FLOW.md](03_USER_FLOW.md) | What each person does step by step, with diagrams and screen sketches |

Diagrams are written in Mermaid, which GitHub draws automatically. Screen sketches are plain-text layouts.

Earlier research behind these decisions (Meta's platform rules, multi-account behaviour, costs) is in the Splashjet `splinh` repository under `Dump/WhatsApp_Direct_Meta_Plan_2026-10-27.md` and `Dump/WhatsApp_Integration_Report_and_Plan_2026-10-27.md`.
